deterministically by `main.ts` (Node 22, stdlib only) to `/output/entry.txt`.

> My agent reviews my code now — it approved a bug I wrote, fixed it, and left a comment saying the original author needs to be more careful.

139 characters, one line, inside the 1–280 gate. No network, no randomness,
no clock — two runs produce byte-identical output.
